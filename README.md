# Jimmy's Bagels — React Scripts

Create React App / react-scripts version of the Jimmy's Bagels website.

All React source files use `.js`; there are no `.jsx` files and no Vite configuration.

## Start
```bash
npm install
npm start
```

## Production build
```bash
npm run build
```

Main files:
- `public/index.html`
- `src/index.js`
- `src/index.css`
- `src/App.js`
- `src/App.css`
